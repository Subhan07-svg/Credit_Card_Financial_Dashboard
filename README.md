# 💳 Credit Card Financial Dashboard | Power BI

## 📌 Project Overview
The Credit Card Financial Dashboard is a data analytics project developed using Microsoft Power BI. It provides insights into credit card transactions, customer demographics, revenue, transaction amounts, interest earned, and customer spending behavior.

The project includes two interactive dashboards:
- **Credit Card Customer Report**
- **Credit Card Transaction Report**

## 🎯 Project Objectives
- Analyze total revenue and interest earned from credit card transactions.
- Monitor transaction amounts and transaction counts.
- Understand customer demographics based on age, gender, education, income, and occupation.
- Analyze revenue by card category, expenditure type, and customer profile.
- Identify the top-performing states based on revenue.
- Compare quarterly and weekly revenue trends.
- Support data-driven business decisions through interactive visualizations.

## 🛠️ Tools & Technologies
- Microsoft Power BI
- Microsoft Excel / CSV
- Data Cleaning and Transformation
- Data Visualization
- Business Intelligence (BI)

## 📈 Key Project Findings
Based on the provided dashboard reports:

- Total revenue is approximately **56.52 million**.
- Total interest earned is approximately **7.98 million**.
- Total transaction amount is approximately **45.53 million**.
- Total transaction count is approximately **667.2K**.
- The Blue card category contributes the highest revenue among the card categories shown.
- Bills represent the highest revenue among the listed expenditure types.
- Businessmen contribute the highest revenue among the customer job categories shown.
- The dashboards provide quarterly and weekly views for analyzing business performance.

*Note: Values are rounded as displayed in the reports.*
